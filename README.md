# Forja3D

Convierte una imagen en un modelo 3D listo para imprimir (STL estanco, a escala en mm).
Web estática: https://nandorro.github.io/forja3d/

Motores en la nube: Hunyuan3D-2 (Hugging Face, gratis) y Meshy (de pago). Las claves se guardan solo en tu navegador.
Hunyuan3D-2 tiene una licencia que excluye UE, Reino Unido y Corea del Sur.
